# Taiga API Reference Index

Source of truth: https://docs.taiga.io/api.html

Load only the file needed for the current task:

- `general.md`: base URL, headers, pagination, OCC/version rules.
- `auth.md`: normal login, token refresh, session/proxy guidance.
- `projects.md`: projects, memberships, roles, milestones/sprints.
- `work-items.md`: epics, user stories/usor, tasks, issues/isu.
- `metadata.md`: statuses, priorities, severities, issue types, filters data.
- `bulk.md`: bulk creation/update patterns and app-level bulk guidance.
- `attachments-history.md`: attachments, comments/history, voting/watching.
